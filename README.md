# DibsUI-Party

Party frames for World of Warcraft: Forever, made to match [DibsUI](https://github.com/DibsCodes/DibsUI-forever).

This addon is in early development.

## Optional dependencies

- **DibsUI**: the party frames work without it. If it is installed, it loads first.
- **Masque**: skins the frame buttons if it is installed.

## Install

Copy the `DibsUI-Party` folder into `World of Warcraft/_forever_/Interface/AddOns/`.
